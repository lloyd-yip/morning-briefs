Webinar strategy

Core problem lane (what THEIR buyers feel):

Deans / district leaders still can’t fill residency seats reliably — conferences create buzz, then nothing compounds.

Who we invite (OUR room-filling motion — not the webinar script):

1. First: state system academic / growth leads (Ideal)

2. Next: Deans of Colleges of Education

3. Then: district CAO / HR

Story arc (THEIR webinar to THEIR audience):

1. Hook — “You’re responsible for residency seats. Why does every cycle still feel like a scramble?”

2. Problem — Event leads and one-off relationships don’t turn into a repeatable fill plan for residencies.

3. Proof — How structured technical assistance actually changes residency operations (their method / examples — not “we built you a list”).

4. Offer — NCTR’s TA as the way to run residencies with less chaos and more predictability.

5. Easy CTA — Book a conversation with NCTR about fit for your college / district / system.

Copy / talk-track beats (about THEIR offer):

1. “One topic: filling residency seats without reinventing the program every year.”

2. “Built for Deans, district HR, and CAOs — not a general ‘education tips’ webinar.”

3. “What changes when residency support is a system, not a heroic staff member.”

4. “State systems: same playbook across campuses.”

5. “Walk away with a clearer fill plan — then talk to NCTR if you want help running it.”

Cadence:

Run that one topic 2–3 times → see who books NCTR → then segment (systems vs single CoE vs large districts).
